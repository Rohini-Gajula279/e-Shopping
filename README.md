# School Management System

A multi-module academic portal that manages student records, academic details, and marks, with separate access for students and admins.

## What it does
- Secure role-based login for students and admins
- Student registration and record management
- Marks entry and management
- Around 1,000–1,200 lines of code, verified with 8 test cases

## Tech Used
- **Backend:** Java, Servlets, JSP, JDBC
- **Database:** MySQL
- **Frontend:** HTML, CSS
- **Testing:** Postman (API testing)

## How to Run
1. Clone the repository
   ```bash
   git clone https://github.com/Rohini-Gajula279/SchoolManagementSystem.git
   ```
2. Open the project in your IDE (Eclipse recommended for Servlet/JSP projects)
3. Set up a MySQL database and update the DB connection details in the config file
4. Deploy the project on a local server (e.g., Apache Tomcat)
5. Open your browser and go to `http://localhost:8080/SchoolManagementSystem`

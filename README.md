# e-Shopping

A full-stack e-commerce web application that lets users browse products, manage a shopping cart, and place orders, while admins manage the product catalog.

## What it does
- User registration and secure login
- Product catalog with add/update/delete (CRUD) operations
- Shopping cart functionality
- REST APIs connecting the frontend to a MySQL database

## Tech Used
- **Backend:** Java, Spring Boot, REST APIs
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

## How to Run
1. Clone the repository
   ```bash
   git clone https://github.com/Rohini-Gajula279/e-Shopping.git
   ```
2. Open the project in your IDE (Eclipse / IntelliJ / VS Code)
3. Create a MySQL database and update the credentials in `application.properties`
4. Run the Spring Boot application:
   ```bash
   mvn spring-boot:run
   ```
5. Open your browser and go to `http://localhost:8080`
